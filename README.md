# CLI reference

Referensi singkat perintah terminal untuk campank.

## Transparansi

Catatan dan riwayat awal repo ini dibuat otomatis. Tanggal commit awal
diatur mundur untuk visualisasi contribution graph, bukan bukti pekerjaan
yang dilakukan pada tanggal tersebut. Tidak ada klaim aktivitas historis nyata.

`generate.py` membuat 121 catatan pada tanggal berbeda sebelum hari ini.
Bersama commit inisialisasi hari ini, totalnya 122 commit pada 122 tanggal.
Jangan jalankan ulang pada repo yang sudah berisi catatan.

## Isi

- `notes/`: kartu referensi CLI yang dibuat otomatis.
- `generate.py`: generator riwayat awal (Python 3 dan Git).

Commit baru berikutnya dapat dibuat dengan tanggal sebenarnya saat referensi
ditambah atau diperbaiki. Atribusi GitHub memerlukan email author yang
terhubung dan terverifikasi di akun tujuan, serta commit di default branch.
